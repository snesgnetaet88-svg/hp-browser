# HP BROWSER — by hypermarket

Браузер на PyQt6 + QtWebEngine: вкладки сверху, плоская панель
навигации, стартовая страница с поиском, гибкие темы и встроенный
OSINT-арсенал. Хакерская тема (чёрный+зелёный со сканлайнами и «матрицей»)
никуда не делась — теперь это одна из тем в списке.

## Скачать

Готовый портативный `.exe` для Windows собирается автоматически и лежит в
разделе [Releases](../../releases): распакуй `HP-Browser-Windows.zip` и запусти
`HP-Browser.exe` — Python ставить не нужно.

Сборку можно запустить вручную на вкладке **Actions → Build Windows EXE →
Run workflow** (укажи тег, например `v1.0.0`) или локально скриптом
`build_windows.bat`.

## Установка

```bash
cd hp-browser
python3 -m pip install --user -r requirements.txt
```

> На отдельных системах QtWebEngine требует библиотек: `libxkbcommon`,
> `libegl`, `libgl`, `libnss3`. Запуск в контейнере — с `--no-sandbox`
> (уже добавляется автоматически вне Windows).

### Windows

```bat
py -m pip install -r requirements.txt
py main.py
```

Нужен Python 3.10+ с сайта python.org (галочка «Add Python to PATH»).
Готовый `HP-Browser.exe` собирается скриптом `build_windows.bat`
(использует PyInstaller) или автоматически в GitHub Actions.

## Быстрые ключи в адресной строке

Перед запросом можно указать движок (как смарт-ключи в браузерах):

| Ключ | Где искать |
|------|-----------|
| `g` | Google |
| `ddg` | DuckDuckGo |
| `y` / `b` | Яндекс / Bing |
| `w` | Wikipedia |
| `gh` | GitHub |
| `yt` | YouTube |
| `maps` | OpenStreetMap |

Пример: `gh hypermarket` → поиск на GitHub, `yt lofi` — на YouTube.

## Настройка

Linux: `~/.config/hp-browser/config.json`, данные — `~/.local/share/hp-browser/`.
Windows: `%APPDATA%\hp-browser\config.json`, данные — `%LOCALAPPDATA%\hp-browser\`.
Переопределить можно переменными `HP_BROWSER_CONFIG` и `HP_BROWSER_DATA`.

На Linux рендеринг по умолчанию программный (`--disable-gpu`): на машинах без
рабочих GBM/Vulkan Chromium падает в сегфолт при старте. На Windows аппаратное
ускорение включено по умолчанию. Принудительно задать режим можно переменной:

```bash
export HP_GPU=1   # всегда аппаратное
export HP_GPU=0   # всегда программное
```

На Windows то же самое: `set HP_GPU=0` перед запуском.

Производительность (почему стало меньше лагов):

- сканлайны статичны по умолчанию — окно не перерисовывается 25 раз в секунду,
  анимация полосы включается в меню «Вид»;
- история пишется на диск отложенно (1.5 с), а не на каждый переход;
- сниффер дописывает в панель только новые строки;
- «матрица» на стартовой странице (только в хакерской теме) замедлена и встаёт,
  когда страница скрыта.

Модуль Leaks работает **без ключа** — по умолчанию использует бесплатные
источники (LeakCheck public, ProxyNova COMB), пароли маскируются.
Если есть платный ключ HaveIBeenPwned (тариф Core 1, $4.39/мес), задай его —
модуль переключится на HIBP:

```bash
export HIBP_API_KEY="ваш_ключ"
```

Без ключа и без интернета модуль сообщит об этом и не упадёт.

## Оговорки

- Sniffer и блокировка трекеров используют один перехватчик: QtWebEngine
  допускает только один `QWebEngineUrlRequestInterceptor` на профиль.
- DoH и отключение WebRTC задаются флагами Chromium и применяются при старте.
- На Linux рендеринг программный (`--disable-gpu`) — так Chromium не падает в
  Vulkan систем без рабочего GBM; на Windows ускорение включено по умолчанию.
  Режим задаётся переменной `HP_GPU`.
- Вне Windows запуск приложения добавляет `--no-sandbox`; сама песочница
  Chromium на Windows работает штатно и не отключается.
- Twitter/Reddit-подобные сайты могут требовать JavaScript — не блокируется.
