# Проект HP Browser — карта разработки

## 1. Обзор проекта
HP Browser — браузер на PyQt6 + QtWebEngine с вкладками, темами, OSINT-инструментами, приватностью и удобствами UI.
Основной стиль/ориентация — минималистичный интерфейс с поддержкой хакерской темы.

Версия/состояние: **дымовые тесты 47/47**, **тесты bookmarks_io 7/7**. Все .py компилируются без ошибок. Последний коммит: `a2e29b5`.

## 2. Архитектура проекта
Проект структурирован модульно:

| Модуль | Назначение |
|---|---|
| `main.py` | Точка входа: применение Chromium-флагов (privacy.apply_env_flags), создание QApplication, запуск MainWindow. Поддерживает `HP_OPEN_URL`, `HP_SELFTEST`, `HP_GPU`. |
| `ui/` | Графический интерфейс: окно, вкладки, тулбары, панели, темы, служебные страницы, фреймлесс-режим. |
| `core/` | Бизнес-логика: браузер (нормализация ввода, поисковики), закладки, история, загрузки, настройки, приватность (флаги/блокировка трекеров), заметки. |
| `tools/` | OSINT-утилиты: WHOIS/DNS/SSL/crt.sh, проверка утечек (HIBP + бесплатные), security-анализ заголовков, сниффер запросов. |
| `utils/` | Брендинг, скриншоты, простой OCR-подобный анализ (PIL). |
| `tests/` | Дымовые тесты UI (offscreen) и тесты импорта/экспорта закладок. |

## 3. Ключевые файлы и их роль
### core
- `core/browser.py` — нормализация ввода (с поддержкой `gh/yt/w/g/ddg/y/b/maps` и др.), `SEARCH_ENGINES`, `DEFAULT_QUICK_LINKS`, `parse/format_quick_links`.
- `core/settings.py` — JSON-настройки с дефолтами (`DEFAULTS`), загрузка/сохранение в `~/.config/hp-browser/config.json`.
- `core/bookmarks.py` — `Bookmarks` (добавление без дублей, удаление, сохранение/загрузка). Связан с `bookmarks_io.py`.
- `core/bookmarks_io.py` — импорт/экспорт закладок в формате Netscape (HTML), с нормализацией `&amp;`, fallback title -> url, пропуск некорректных URL.
- `core/history.py` — история посещений (items, добавление, фильтр, сохранение в `history.json`).
- `core/downloads.py` — `DownloadManager`, `human(size)`, хранение истории загрузок, отмена/очистка завершённых.
- `core/notes.py` — простые заметки (создание/хранение/экспорт JSON).
- `core/privacy.py` — `PrivacyGuard` (блокировка трекеров по подстроке хоста), `chromium_flags` (сборка QTWEBENGINE_CHROMIUM_FLAGS), `gpu_enabled()` (HP_GPU по умолчанию выключен), `apply_env_flags`, шаблон DoH.

### ui
- `ui/window.py` — `MainWindow`: безрамочный режим (CSD), панель вкладок (DragToolBar), кнопки окна (WindowButtons), тулбары навигации/инструментов, меню-гамбургер, сайдбар (закладки+история), статусбар (zoom, приватность, загрузки), приватное окно, переключение тем, сессия (restore_session, сохранение session_tabs), служебные страницы (`open_page` для hp://settings/downloads/clear/about/shortcuts), недавние закладки/закрытые вкладки.
- `ui/tabs.py` — `BrowserTabs` (stack + внешний QTabBar), `BrowserView` (контекстное меню: открыть ссылку/изображение в новой вкладке, сохранить картинку, копировать, загрузка через page().download), `BrowserPage` (target=_blank -> новая вкладка), `page_url/current_page/views`, `add_page/replace_widget`, `setTabsClosable(True)`.
- `ui/pages.py` — служебные страницы-вкладки: `PageBase`, `SettingsPage` (флаги темы/поисковика/дом.страницы/панелей/приватности/DoH/DNT/proxy/user-agent/quick_links), `DownloadsPage` (авто-обновление по `manager.changed`), `ClearDataPage` (очистка истории/закладок/загрузок/кэша), `AboutPage` (моноширинный ASCII-логотип, версии PyQt6/Qt), `ShortcutsPage`.
- `ui/themes.py` — 7 тем: classic, classic-dark, hacker, comfort, nord, solarized, dark; `qss(theme)` с QSS для всего UI, включая стили страниц (`#page_title` и др.).
- `ui/toolbar.py` — NavToolBar/ToolsBar: back/forward/home/reload/bookmark/downloads/menu, адресная строка с автодополнением, приватность-кнопка со счётчиком, zoom-кнопка, ПКМ по навигационным кнопкам -> история навигации (до 15 записей), кастомное контекстное меню истории.
- `ui/shortcuts.py` — `SHORTCUTS` + `install()` + `_digit_shortcuts` (Ctrl+1..9, 9 -> последняя).
- `ui/viewops.py` — масштаб, поиск по странице, переключение вкладок (next/prev/focus_tab), полноэкран, действия вкладок (menu контекста вкладки), `SHORTCUT_HELP`.
- `ui/extras.py` — доп. действия (импорт/экспорт закладок, экспорт истории, заметки, OSINT/leaks/security/sniffer, show_about -> открывает hp://about).
- `ui/actions.py` — `ToolsActions` (инструменты).
- `ui/sidebar.py`, `ui/findbar.py`, `ui/tool_panel.py`, `ui/frameless.py`, `ui/scanlines.py`, `ui/startpage.py` — вспомогательные UI-компоненты.

## 4. Реализованные фичи (краткий перечень)
Базовые: вкладки, навигация, закладки/история (боковая панель с живым фильтром), стартовая с плитками быстрых ссылок (матрица только у hacker), сканлайны (CRT), поиск по странице (счётчик), масштаб (сохранение), сессия (восстановление вкладок), приватное окно (отдельный профиль).
Продвинутые: служебные страницы-вкладки (hp://), OSINT (whois/dns/ssl/crt.sh), Leaks (email), Security (оценка заголовков), Sniffer (перехват запросов с блокировкой трекеров PrivacyGuard), режим чтения, тёмная тема сайтов, скриншот, PDF, заметки (создание/экспорт JSON), экспорт истории, импорт/экспорт закладок (Netscape HTML), User-Agent настраиваемый, прокси и Do Not Track, быстрые ключи поиска (gh/yt/w/g/ddg/y/b/maps), Ctrl+1..9, меню недавних закладок и закрытых вкладок, статус загрузок и счётчик блокированных трекеров.

## 5. Журнал ошибок и обходов (Error & Workaround Log)
### 5.1 QtWebEngine / новые окна (target=_blank)
- Симптом: ссылки target=_blank открывались отдельным окном вместо новой вкладки.
- Причина: стандартный QWebEnginePage.createWindow не делегировал создание в браузер.
- Решение: в `ui/tabs.py` добавлен `BrowserPage` с кастомным `createWindow`/opener, `_open_new_tab` делегирует в `MainWindow.add_tab()` (или `BrowserTabs.add_tab()`), тест `_` в smoke-тестах проверяет поведение.

### 5.2 Выход элементов за рамки окна / переполнение
- Симптом: кнопки управления окном, элементы могли выходить за границы.
- Причина: неверная компоновка в `WindowButtons`, минимальные размеры.
- Решение: в `ui/frameless.py` кнопки добавлены в свой layout, заданы `Fixed` policy, `setMinimumSize(sizeHint())`, `MainWindow.setMinimumWidth(620)`, выравнивания UI — зафиксировано (см. коммит a2e29b5 и харнесы в /tmp/opencode по проверкам).

### 5.3 Темы — галочки и повторы
- Симптом: в меню-баре/гамбургере галочка активной темы могла теряться (одно действие на тему записывалось в dict). Также были дубли светлых тем.
- Причина: `_theme_actions[name] = act` перезаписывал одно действие; `QActionGroup` был exclusive и конфликтовал между двумя меню.
- Решение: переведено хранение на список действий на тему (`_theme_actions.setdefault(name, []).append(act)`), `_sync_theme_actions` выставляет галочки по имени темы для всех действий, `QActionGroup.setExclusive(False)`. Убраны дубли тем (`light` восстанавливался/приводился к корректному набору из 7 тем).

### 5.4 Служебные страницы вместо диалогов
- Симптом: большие диалоги (Настройки/Загрузки/Очистить/О программе/Горячие клавиши) открывались окнами.
- Причина: старая реализация (`ui/settings_dialog.py`, `ui/clear_data.py`, `ui/downloads.py`).
- Решение: созданы `ui/pages.py` (PageBase + страницы), `MainWindow.open_page(kind)` с дедупликацией по `hp://…`, импорты/открытие переведены на страницы. Старые диалоги удалены, тесты обновлены.

### 5.5 Chromium/GPU (Vulkan/GBM)
- Симптом: сегфолты/крэши, warnings `GBM is not supported... Fallback to Vulkan rendering`, `GPUInfo not initialized`, периодические падения при запуске в окружении Wayland/XWayland.
- Причина: QtWebEngine/Chromium пытается использовать GPU (Vulkan/GBM) там, где он недоступен.
- Решение: по умолчанию `gpu_enabled()` возвращает False (`HP_GPU` не задан -> программный рендер). `chromium_flags()` добавляет `--disable-gpu` (и `--disable-software-rasterizer` в актуальной версии), флаги применяются через `apply_env_flags` ДО создания `QApplication` (core/privacy.py, main.py). При запуске через systemd задаётся `HP_GPU=0` и корректные env (DISPLAY/WAYLAND/XDG_*).

### 5.6 SQLite / сохранение (NOT NULL constraint failed) — история/база
- В кодовой базе прямой SQLite с NOT NULL не массово просматривается; хранение преимущественно JSON (`core/settings.py`, `core/history.py`, `core/bookmarks.py`, `core/downloads.py`, `core/notes.py`). Специфических случаев NOT NULL в логах не зафиксировано (текущие тесты проходят). При добавлении записей используются значения по умолчанию.

### 5.7 Импорты/зависимости
- PyQt6/QWebEngine — в `requirements.txt`. Компиляция всех .py проходит. smoke-тесты стабильны в offscreen.

## 6. Текущее состояние
### Работает идеально
- Дымовые UI-тесты: 47/47. Тесты bookmarks_io: 7/7.
- Безрамочный UI (CSD), корректная раскладка вкладок сверху, панель навигации ниже, растяжение адресной строки, меню-гамбургер.
- Служебные страницы-вкладки (hp://settings/downloads/clear/about/shortcuts), дедупликация.
- Темы (7), синхронизация галочек в меню-баре и гамбургере, корректные стили страниц.
- Навигация с ПКМ-меню истории, автодополнение из истории/закладок, быстрые ключи поиска.
- OSINT/leaks/security/sniffer + PrivacyGuard (счётчик блокировок в статусбаре).
- Загрузки с автодополнением статуса, приватное окно, сессия, экспорт/импорт закладок (Netscape HTML).

### Работает, но с оговорками
- Chromium/GPU: на некоторых системах возможны ворнинги `GPUInfo not initialized` — обход через `HP_GPU=0` и флаги `--disable-gpu --disable-software-rasterizer`.
- Визуальная съёмка через KWin-скрипт (`utils/screenshot.py`) может зависеть от окружения (Wayland/KWin) — функционал для отладки.
- Локализация/кодировка: при запуске через systemd иногда уведомление о `C` locale -> переключение на `C.UTF-8` (информационное).

### Не реализовано / требует доработки
- Значок закрытия вкладки присутствует через `setTabsClosable(True)` + `tabButton`, но в некоторых QSS/стилях может выглядеть стандартным — можно доработать иконку (QIcon из style/спрайт).
- На светлых темах отдельные элементы (кнопки/hover) иногда требуют тонкой правки QSS (микродоработки по визуалу).
- Некоторые инструменты (OSINT/sniffer) завязаны на внешние запросы — при отсутствии сети/блокировках дают осмысленные сообщения, но поведение зависит от окружения.

### Временные костыли
- Запуск с `HP_GPU=0` и явными Chromium-флагами в production/тестовом окружении (устраняет GPU-крэши) — рекомендуется оставить как безопасное поведение по умолчанию (реализовано).
- `QActionGroup.setExclusive(False)` + ручная синхронизация галочек тем (для работы в двух меню одновременно) — рабочее решение, можно считать архитектурным компромиссом.

## 9. Вывод
Проект HP Browser находится в стабильном рабочем состоянии (все тесты зелёные). Основные архитектурные блоки реализованы: безрамочный UI, вкладки-страницы вместо диалогов, темы, инструменты OSINT и приватность. Выявленные проблемы (GPU/Chromium, синхронизация галочек тем) имеют рабочие обходы и частично зафиксированы в коде. Требуются небольшие UI-доработки (иконка закрытия вкладки, контраст на светлых темах) и точечные рефакторинги.
